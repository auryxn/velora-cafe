# Velora Café

> Часть портфолио: [сайт-портфолио](https://auryxn.github.io/site-admin/) — репозиторий сайта [site-admin](https://github.com/auryxn/site-admin).

> Сайт кофейни/ресторана с редактируемой админкой: публичная страница (React/Vite) + REST API на Node + SQLite.

## Что это

Velora Café — сайт городской кофейни в Ужуписе (Вильнюс) со specialty-кофе и
завтраками весь день. По функциональности это витрина заведения: hero-блок,
раздел о кофейне, меню по категориям, галерея, отзывы, бронирование и контакты.

Проект состоит из двух частей: **сайт для гостей** и **админка**, через которую
владелец сам редактирует весь контент без программиста — позиции меню и цены,
отзывы, фото галереи, тексты и контакты, а также заявки на бронирование.

И сайт, и админка, и API, и база данных — это один Node-процесс без внешних
зависимостей на бэкенде (используются встроенные модули Node). Контент хранится
в SQLite, поэтому данные переживают перезапуск.

> Технически кодовую базу проекта разделяет с сайтом Kavinė Koralai: та же
> архитектура и админка, отличается бренд, контент и тексты.

## Возможности

- **Публичный сайт** (`/`): hero, о кофейне, меню по категориям (кофе, блюда,
  десерты), галерея, отзывы, блок бронирования, контакты.
- **Админка** (`/admin`) с вкладками:
  - **Menu** — позиции, цены, описания, наличие, сортировка;
  - **Reviews** — отзывы (имя, роль, текст, рейтинг);
  - **Gallery** — фото с подписями;
  - **Settings** — брендовые тексты, адрес, часы работы, контакты, соцсети,
    заголовки секций;
  - **Reservations** — заявки на бронирование с их статусом.
- **Загрузка изображений** в `uploads/`.
- **REST API** под `/api`.
- **Аутентификация** админки: пароль хранится как хеш с солью, вход по
  HMAC-подписанному токену (без сторонних библиотек).
- **SQLite-база** `velora.sqlite` с идемпотентным сидированием.

Бэкенд использует только встроенные модули Node (`node:http`, `node:sqlite`,
`node:crypto`, `node:fs`) — дополнительных серверных зависимостей нет.

## Стек

- **Frontend:** React + Vite + Tailwind CSS, иконки lucide-react
- **Backend:** Node.js (встроенные модули, без Express)
- **БД:** SQLite через `node:sqlite`
- **Сборка:** Vite с двумя точками входа (`index.html` — сайт, `admin.html` —
  админка)
- **Тесты/скриншоты:** Playwright (dev-зависимость)

## Запуск

### Продакшн-режим (собранный сайт + API отдаёт один сервер)

```bash
npm install
npm run build     # собирает сайт и админку в dist/
npm start         # запускает Node-сервер (по умолчанию порт 4000)
```

Откройте:

- Сайт: http://localhost:4000/
- Админка: http://localhost:4000/admin

**Логин админки по умолчанию:** `admin` / `admin123`.

Для реального деплоя смените пароль в базе и задайте переменную окружения
`VELORA_SECRET` (секрет для подписи токенов).

Полезные команды:

```bash
npm run db:seed     # создать БД и наполнить её контентом
npm run dev:server  # только API-сервер
```

### Режим разработки (Vite + проксирование API)

Терминал 1:

```bash
npm run dev:server    # API на :4000
```

Терминал 2:

```bash
npm run dev           # Vite; /api и /uploads проксируются на :4000
```

### Проверка API

```bash
curl http://localhost:4000/api/health
curl http://localhost:4000/api/menu
```

## Структура проекта

```
index.html            точка входа публичного сайта
admin.html            точка входа админки
VeloraCafe.jsx        вся публичная страница (компонент)
src/
  main.jsx            монтирование сайта
  admin/main.jsx      SPA админки
  style.css, admin/admin.css
server/
  db.js               схема БД, сидирование, хеширование паролей
  index.js            HTTP-сервер: REST API + отдача статики
  auth.js             выпуск/проверка HMAC-токенов
assets/               изображения (hero, интерьер, десерты)
uploads/, videos/     загруженные пользователем файлы
velora.sqlite         база данных SQLite
```
